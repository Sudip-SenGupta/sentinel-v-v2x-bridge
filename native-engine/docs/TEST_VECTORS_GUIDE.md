/**
 * @file TEST_VECTORS_GUIDE.md
 * @brief IEEE 1609.2 COER Test Vectors - Complete Guide
 *
 * # Test Vector Documentation
 *
 * This document describes the comprehensive test vector suite for validating
 * the COER (Canonical Octet Encoding Rules) decoder implementation.
 *
 * ## Overview
 *
 * Test vectors are realistic IEEE 1609.2 V2X messages in COER format.
 * They cover:
 *
 * - **Valid Messages** (5 vectors): Different message types and structures
 * - **Malformed Messages** (5 vectors): Error handling and robustness
 * - **Performance** (1 vector): Large messages near DSRC limits
 *
 * All vectors use realistic data structures representing actual V2X use cases.
 *
 * ## Quick Reference
 *
 * | Vector Name | Type | Size | Purpose |
 * |-------------|------|------|---------|
 * | UNSIGNED_MINIMAL | Valid | 18 bytes | Minimal format validation |
 * | SIGNED_TYPICAL_BSM | Valid | ~760 bytes | Typical signed message |
 * | SIGNED_WITH_CHAIN | Valid | ~1900 bytes | Certificate chain validation |
 * | SIGNED_EMERGENCY_ALERT | Valid | Variable | Small emergency alert |
 * | SIGNED_MAXIMUM_SIZE | Valid | ~1000 bytes | Performance/large message |
 * | MALFORMED_TRUNCATED | Error | 32/256 bytes | Buffer underflow |
 * | MALFORMED_INVALID_VERSION | Error | - | Format rejection |
 * | MALFORMED_EMPTY | Error | 0 bytes | Minimum validation |
 * | MALFORMED_SHORT_HEADER | Error | 2 bytes | Header completion check |
 * | MALFORMED_ZERO_PAYLOAD_SIGNED | Edge | - | Semantic edge case |
 *
 * ---\n\n",
 *
 * ## Detailed Vector Descriptions
 *
 * ### 1. UNSIGNED_MINIMAL\n\n",
 *
 * **Purpose**: Validate parser handles simplest valid message format\n\n",
 *
 * **Structure**:\n",
 * ```\n",
 * [Header]          0x03   (protocol v3, message type: unsigned)\n",
 * [Payload Length]  0x000F (15 bytes, big-endian)\n",
 * [Payload]         15 bytes of minimal BSM data\n",
 * ```\n\n",
 *
 * **Message Interpretation**:\n",
 * - Protocol Version: 3 (IEEE 1609.2-2016)\n",
 * - Message Type: Unsigned (bit 1 = 0)\n",
 * - Encryption: None (bit 2 = 0)\n",
 * - Payload: 15 bytes representing minimal vehicle state\n",
 * - Total Message: 18 bytes\n\n",
 *
 * **Parser Validation**:\n",
 * - Entry point for format validation\n",
 * - Tests header byte parsing (version + type extraction)\n",
 * - Tests big-endian length field reading (2-byte value)\n",
 * - Tests payload extraction (follows length field)\n\n",
 *
 * **Expected Results**:\n",
 * ```cpp\n",
 * msg.message_type == 0x03\n",
 * msg.protocol_version == 3\n",
 * msg.is_signed() == false\n",
 * msg.payload.size() == 15\n",
 * msg.is_encrypted() == false\n",
 * ```\n\n",
 *
 * **Phase 2 Integration**: Not applicable (unsigned, no crypto)\n",
 *\n",
 *\n",
 *
 * ### 2. SIGNED_TYPICAL_BSM\n\n",
 *
 * **Purpose**: Validate parsing of typical signed V2X message\n\n",
 *
 * **Real-World Scenario**:\n",
 * A vehicle broadcast a Cooperative Awareness Message (CAM):\n",
 * - Sender: Tesla vehicle at 37.7749°N, 122.4194°W (San Francisco)\n",
 * - Speed: 65 km/h\n",
 * - Heading: 45°\n",
 * - Signature: ECDSA P-256 from vehicle's OEM certificate\n",
 * - Broadcast Rate: 10 Hz (100ms intervals)\n\n",
 *
 * **Structure**:\n",
 * ```\n",
 * [Header]                  0x02 (signed message)\n",
 * [Payload Length]          0x005A (90 bytes)\n",
 * [Payload]                 90 bytes CAM/BSM data\n",
 * [Signature Algorithm]     0x04 (ECDSA P-256)\n",
 * [ECDSA r component]       32 bytes (big-endian)\n",
 * [ECDSA s component]       32 bytes (big-endian)\n",
 * [Issuer Certificate]      ~600 bytes (X.509 DER-encoded)\n",
 * ```\n\n",
 *
 * **Payload Content** (representative V2X BSM fields):\n",
 * - Timestamp: UTC timestamp (32-bit milliseconds)\n",
 * - Latitude: ~37.7749° (fixed-point encoded)\n",
 * - Longitude: ~-122.4194° (fixed-point encoded)\n",
 * - Elevation: ~10m above sea level\n",
 * - Speed: 18.06 m/s (65 km/h)\n",
 * - Heading: 45 degrees (0-359)\n",
 * - Acceleration: {0.5, 0.2, 0.0} m/s²\n",
 * - Additional telemetry: Brake status, turn signals, etc.\n\n",
 *
 * **Parser Validation**:\n",
 * - Header byte with signature bit set (0x02)\n",
 * - Payload length: 90 bytes\n",
 * - Signature algorithm extraction (ECDSA P-256)\n",
 * - Signature component parsing (r || s = 64 bytes)\n",
 * - X.509 certificate extraction (DER format)\n",
 * - No certificate chain (chain should be empty)\n\n",
 *
 * **Expected Results**:\n",
 * ```cpp\n",
 * msg.message_type == 0x02\n",
 * msg.is_signed() == true\n",
 * msg.payload.size() == 90\n",
 * msg.is_encrypted() == false\n",
 * \n",
 * auto sig = COERDecoder::extract_signature(msg);\n",
 * sig.size() == 64  // r (32) + s (32)\n",
 * \n",
 * auto cert = COERDecoder::extract_issuer_certificate(msg);\n",
 * cert.size() > 300 && cert.size() < 1500\n",
 * cert[0] == 0x30  // X.509 SEQUENCE tag\n",
 * ```\n\n",
 *
 * **Phase 2 Integration**:\n",
 *```cpp\n",
 * auto payload = COERDecoder::get_payload(msg);\n",
 * auto signature = COERDecoder::extract_signature(msg);\n",
 * auto issuer = COERDecoder::extract_issuer_certificate(msg);\n",
 * \n",
 * // Feed to Phase 2 verification\n",
 * auto epoch = V2XCryptoEngine::initialize();\n",
 * auto verify_result = epoch.verify_ecdsa_signature(\n",
 *     payload,    // Exact bytes that were signed\n",
 *     signature,  // ECDSA r || s (64 bytes)\n",
 *     issuer      // Public key certificate\n",
 * );\n",
 * \n",
 * if (verify_result.valid) {\n",
 *     LOGI(\"Message authenticated - accepted\");\n",
 * } else {\n",
 *     LOGW(\"Signature invalid - dropping message\");\n",
 * }\n",
 * ```\n\n",
 *\n",
 *\n",
 *
 * ### 3. SIGNED_WITH_CHAIN\n\n",
 *
 * **Purpose**: Validate certificate chain extraction and structure\n\n",
 *
 * **Real-World Scenario**:\n",
 * Vehicle sends message with full PKI chain:\n",
 * - Issuer Cert: Tesla Model 3 (VIN: 5YJ3E1EA*****0001) certificate\n",
 * - Chain[0]: Tesla OEM CA (issues all Tesla vehicle certs)\n",
 * - Chain[1]: National Root CA (e.g., DOT/NHTSA Root)\n\n",
 *
 * **Chain Structure** (certificate hierarchy):\n",
 * ```\n",
 * Message signed by: Vehicle Private Key\n",
 * Signature verified with: Issuer Certificate\n",
 * Issuer Cert signed by: Intermediate CA (Chain[0])\n",
 * Intermediate CA signed by: Root CA (Chain[1])\n",
 * Root CA: Self-signed (trusted anchor)\n",
 * ```\n\n",
 *
 * **Structure**:\n",
 * ```\n",
 * [Header]           0x02 (signed)\n",
 * [Payload Length]   0x0050 (80 bytes)\n",
 * [Payload]          80 bytes V2X data\n",
 * [Signature]        64 bytes\n",
 * [Issuer Cert]      ~600 bytes\n",
 * [Chain Depth]      0x02 (2 certs)\n",
 * [Chain[0]]         Intermediate CA (~600 bytes)\n",
 * [Chain[1]]         Root CA (~600 bytes)\n",
 * ```\n\n",
 *
 * **Parser Validation**:\n",
 * - Chain depth indicator parsing (0x02 = 2 certificates)\n",
 * - Multiple certificate extraction\n",
 * - Certificate boundary detection\n",
 * - Proper ordering (issuer → root)\n\n",
 *
 * **Expected Results**:\n",
 * ```cpp\n",
 * auto chain = COERDecoder::extract_certificate_chain(msg);\n",
 * chain.size() == 2\n",
 * \n",
 * chain[0].size() > 0  // Intermediate CA\n",
 * chain[1].size() > 0  // Root CA\n",
 * \n",
 * chain[0][0] == 0x30  // SEQUENCE tag\n",
 * chain[1][0] == 0x30\n",
 * ```\n\n",
 *
 * **Phase 2 Integration**:\n",
 * ```cpp\n",
 * // Step 1: Verify message signature\n",
 * auto issuer = COERDecoder::extract_issuer_certificate(msg);\n",
 * auto sig = COERDecoder::extract_signature(msg);\n",
 * auto payload = COERDecoder::get_payload(msg);\n",
 * \n",
 * auto sig_valid = engine.verify_ecdsa_signature(payload, sig, issuer);\n",
 * if (!sig_valid.valid) return false;\n",
 * \n",
 * // Step 2: Validate certificate chain\n",
 * auto chain = COERDecoder::extract_certificate_chain(msg);\n",
 * auto chain_valid = engine.validate_certificate_chain(issuer, chain);\n",
 * if (!chain_valid) return false;\n",
 * \n",
 * LOGI(\"Message fully authenticated via chain-of-trust\");\n",
 * ```\n\n",
 *\n",
 *\n",
 *
 * ### 4. SIGNED_EMERGENCY_ALERT\n\n",
 *
 * **Purpose**: Validate parsing of small, safety-critical messages\n\n",
 *
 * **Real-World Scenario**:\n",
 * Hard Braking Alert from vehicle ahead:\n",
 * - Vehicle detects rapid deceleration (>5 m/s²)\n",
 * - Broadcasts emergency alert to nearby vehicles within 300m\n",
 * - Alert code: 0x01 (hard braking)\n",
 * - Latency requirement: <50ms\n",
 * - Broadcast: Single (not repeated like CAM)\n\n",
 *
 * **Structure**:\n",
 * ```\n",
 * [Header]                  0x02 (signed)\n",
 * [Payload Length]          0x0020 (32 bytes - small alert data)\n",
 * [Payload]                 32 bytes emergency alert\n",
 * [Signature Algorithm]     0x04 (ECDSA P-256)\n",
 * [Signature]               64 bytes\n",
 * [Issuer Certificate]      ~600 bytes\n",
 * ```\n\n",
 *
 * **Payload Interpretation**:\n",
 * ```\n",
 * Byte 0: Alert Type (0x01 = hard braking)\n",
 * Byte 1-3: Timestamp (relative time from vehicle)\n",
 * Byte 4-7: Position (latitude)\n",
 * Byte 8-11: Position (longitude)\n",
 * Byte 12-15: Severity (0-100%)\n",
 * Byte 16-31: Reserved/Additional context\n",
 * ```\n\n",
 *\n",
 * **Parser Validation**:\n",
 * - Smaller payload size (32 vs 90+ for BSM)\n",
 * - Still requires signature for authenticity\n",
 * - Message type = 0x02 (signed)\n\n",
 *\n",
 * **Expected Results**:\n",
 * ```cpp\n",
 * msg.payload.size() == 32\n",
 * msg.payload[0] == 0x01  // Alert type: hard braking\n",
 * msg.is_signed() == true\n",
 * COERDecoder::extract_signature(msg).size() == 64\n",
 * ```\n\n",
 *\n",
 *\n",
 *
 * ### 5. SIGNED_MAXIMUM_SIZE\n\n",
 *
 * **Purpose**: Validate parser performance with maximum-size messages\n\n",
 *\n",
 * **Why This Matters**:\n",
 * - DSRC V2X messages are limited by channel bandwidth\n",
 * - Maximum practical message size: ~2000 bytes\n",
 * - Parser must handle near-maximum sizes efficiently\n",
 * - Real-world bottleneck: 6 Mbps channel × 100ms = 75 KB available\n",
 * - V2X messages compete with other users on same DSRC channel\n",
 * - Typical message: 200-800 bytes\n",
 * - Large message: 800-1500 bytes (rare)\n\n",
 *\n",
 * **Test Vector Size**: ~1000 bytes total\n",
 * **Payload Size**: 896 bytes (large telemetry dump)\n\n",
 *\n",
 * **Payload Content**:\n",
 * - Complete vehicle state (all sensors)\n",
 * - Extended kinematic data\n",
 * - Road condition observations\n",
 * - Multiple trajectory points\n\n",
 *\n",
 * **Expected Results**:\n",
 * ```cpp\n",
 * msg.payload.size() == 896\n",
 * msg.total_size() > 950  // Includes signature and cert\n",
 * \n",
 * // Performance check\n",
 * auto start = std::chrono::high_resolution_clock::now();\n",
 * auto msg = COERDecoder::parse(raw_bytes);\n",
 * auto end = std::chrono::high_resolution_clock::now();\n",
 * auto duration = std::chrono::duration_cast<std::chrono::microseconds>\n",
 *     (end - start).count();\n",
 * \n",
 * EXPECT_LT(duration, 50000);  // < 50ms\n",
 * ```\n\n",
 *\n",
 *\n",
 * ## Error Test Vectors\n\n",
 *\n",
 * ### MALFORMED_TRUNCATED\n\n",
 *\n",
 * **Scenario**: Network packet loss - message arrives incomplete\n\n",
 *\n",
 * **Structure**:\n",
 * ```\n",
 * [Header]         0x02 (signed)\n",
 * [Payload Length] 0x0100 (256 bytes expected)\n",
 * [Actual Bytes]   Only 32 bytes present\n",
 * ```\n\n",
 *\n",
 * **Expected Exception**: `COERBufferException`\n",
 * **Error Message**: "Buffer underflow: expected 256 bytes, got only 32"\n\n",
 *\n",
 * **Parser Responsibility**:\n",
 * - Detect mismatch between declared length and actual data\n",
 * - Throw exception before attempting access beyond buffer\n",
 * - Prevent buffer over-read attacks\n\n",
 *\n",
 * ### MALFORMED_INVALID_VERSION\n\n",
 *\n",
 * **Scenario**: Future unknown protocol version\n\n",
 *\n",
 * **Structure**:\n",
 * ```\n",
 * [Header] 0x73 (version bits = 0x07, invalid)\n",
 * ```\n\n",
 *\n",
 * **Expected Exception**: `COERFormatException`\n",
 * **Error Message**: "Unsupported protocol version: 7"\n\n",
 *\n",
 * **Parser Responsibility**:\n",
 * - Only accept known versions (currently: 1-3)\n",
 * - Reject unknown versions for forward compatibility\n",
 * - Prevent potential security issues from new (unknown) encodings\n\n",
 *\n",
 * ### MALFORMED_EMPTY_MESSAGE\n\n",
 *\n",
 * **Scenario**: Zero-length message\n\n",
 *\n",
 * **Expected Exception**: `COERBufferException`\n",
 * **Error Message**: "Message too short: 0 bytes (minimum 3)"\n\n",
 *\n",
 * ### MALFORMED_SHORT_HEADER\n\n",
 *\n",
 * **Scenario**: Incomplete header (2 bytes instead of 3)\n\n",
 *\n",
 * **Structure**:\n",
 * ```\n",
 * [Header]      0x02\n",
 * [Length MSB]  0x03\n",
 * [Length LSB]  (missing)\n",
 * ```\n\n",
 *\n",
 * **Expected Exception**: `COERBufferException`\n",\n",
 *\n",
 * ## Test Usage Patterns\n\n",
 *\n",
 * ### Pattern 1: Valid Message Parsing\n\n",
 * ```cpp\n",
 * // In test_coer_decoder_vectors.cpp\n",
 * TEST_F(COERDecoderTest, ParseSignedBSMMessage) {\n",
 *     COERMessage msg = parse_hex_message(SIGNED_TYPICAL_BSM_HEX);\n",
 *     EXPECT_EQ(msg.message_type, 0x02);\n",
 *     EXPECT_TRUE(msg.is_signed());\n",
 *     EXPECT_EQ(msg.payload.size(), 90);\n",
 * }\n",
 * ```\n\n",
 *\n",
 * ### Pattern 2: Component Extraction\n\n",
 * ```cpp\n",
 * TEST_F(COERDecoderTest, ExtractSignatureComponent) {\n",
 *     COERMessage msg = parse_hex_message(SIGNED_TYPICAL_BSM_HEX);\n",
 *     auto signature = COERDecoder::extract_signature(msg);\n",
 *     EXPECT_EQ(signature.size(), 64);\n",
 * }\n",
 * ```\n\n",
 *\n",
 * ### Pattern 3: Error Handling\n\n",
 * ```cpp\n",
 * TEST_F(COERDecoderTest, TruncatedMessageThrows) {\n",
 *     EXPECT_THROW(\n",
 *         parse_hex_message(MALFORMED_TRUNCATED_HEX),\n",
 *         COERBufferException\n",
 *     );\n",
 * }\n",
 * ```\n\n",
 *\n",
 * ### Pattern 4: Phase 2 Integration\n\n",
 * ```cpp\n",
 * TEST_F(COERDecoderTest, Phase2IntegrationWorkflow) {\n",
 *     COERMessage msg = parse_hex_message(SIGNED_TYPICAL_BSM_HEX);\n",
 *     \n",
 *     auto payload = COERDecoder::get_payload(msg);\n",
 *     auto sig = COERDecoder::extract_signature(msg);\n",
 *     auto cert = COERDecoder::extract_issuer_certificate(msg);\n",
 *     \n",
 *     // Phase 2 expects these exact components\n",
 *     auto result = engine.verify_ecdsa_signature(payload, sig, cert);\n",
 *     EXPECT_TRUE(result.valid);\n",
 * }\n",
 * ```\n\n",
 *\n",

 * ## Test Vector Data Format\n\n",
 *\n",
 * All vectors are hex-encoded strings for easy editing and review.\n",
 * Conversion to bytes happens at test runtime.\n\n",
 *\n",
 * **Example**: UNSIGNED_MINIMAL\n",
 * ```\n",
 * Hex String:     \"03 000F 01020304...\"\n",
 * Decoded Bytes: [0x03, 0x00, 0x0F, 0x01, 0x02, 0x03, 0x04, ...]\n",
 * \n",
 * Interpretation:\n",
 *   [0]       = 0x03   → Header (version 3, unsigned)\n",
 *   [1:3]     = 0x000F → Payload length (15 bytes, big-endian)\n",
 *   [3:18]    = [data] → Payload (15 bytes)\n",
 * ```\n\n",
